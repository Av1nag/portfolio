Selected work

Personal project, built and self-hosted

Worklog

A daily work journal that captures what I did while it's fresh, so it's ready when a self-review or resume update comes around.

Every entry answers the same few questions: what I did, the issue, the solution, and the win, tagged by how complex the work was. That structure makes entries easy to turn into review notes or resume bullets later. There's also a to-do list, and it's multi-user, free, and open source.

Under the hood it uses Argon2 password hashing, database-backed sessions, and a REST API where every query is limited to the signed-in user. It runs under systemd on my own Linux server, with automatic HTTPS and daily backups.

Node.js, Express, PostgreSQL, JavaScript, Caddy, Linux
